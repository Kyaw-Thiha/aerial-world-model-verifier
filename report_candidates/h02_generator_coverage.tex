\section{Generator coverage with path control}
\label{sec:h02-generator-coverage}

\paragraph{Scope.}
Only world models that accept a path or camera pose as control are in scope, because the
verifier asks whether the depicted attitude follows the attitude the commanded path requires.
Text-intention models and models without camera control are listed as excluded.

\paragraph{Inventory.}
Table~\ref{tab:h02-inventory} records the control parameterization, whether roll is carried,
the released weights, licence, gating and expected cost. SolarWM-Wan2.2-5B is the only
released model that both takes a camera trajectory and is practical for this pilot;
Aero-World has no public code or weights, CT-1 predicts a trajectory rather than video, and
CameraCtrl/MotionCtrl/ReCamMaster are older smaller-backbone controllers not run here.
